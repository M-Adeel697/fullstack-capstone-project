# User Story Template

**Title:**
As a [type of user], I want [an action or feature] so that [benefit/reason].

**Example:**

**Title:** Search for gift items by category

As a user of GiftLink, I want to search for available items by category, so that I can quickly find items relevant to my needs without scrolling through the entire list.

**Acceptance Criteria:**
1. Given I am on the GiftLink homepage, when I enter a category in the search bar, then only items matching that category are displayed.
2. Given no items match the search category, when I search, then a "no items found" message is displayed.
3. Given I clear the search field, when I press search again, then all items are displayed.

**Priority:** High

**Story Points:** 3

---

## Additional User Stories for GiftLink

1. As a new user, I want to register an account, so that I can list and claim items.
2. As a registered user, I want to log in securely, so that I can access my profile and listings.
3. As a user, I want to view detailed information about an item, so that I can decide if I want to claim it.
4. As a user, I want to leave a comment on an item, so that I can ask the lister questions.
5. As a user, I want to edit my profile information, so that my contact details stay current.
6. As a user, I want to list an item I no longer need, so that others can claim it for free.
7. As a user, I want to see the most recently listed items first, so that I can find fresh items quickly.
8. As a user, I want the site to work on my mobile device, so that I can browse listings on the go.
