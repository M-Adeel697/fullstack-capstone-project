# User Story Template

**Title:**
As a [type of user], I want [an action or feature] so that [benefit/reason].

**Example:**

**Title:** Search for gift items by category

As a user of GiftLink, I want to search for available items by category, so that I can quickly find items relevant to my needs without scrolling through the entire list.

**Acceptance Criteria:**
1. Given I am on the GiftLink homepage, when I enter a category in the search bar, then only items matching that category are displayed.
2. Given no items match the search category, when I search, then a "no items found" message is displayed.
3. Given I clear the search field, when I press search again, then all items are displayed.

**Priority:** High

**Story Points:** 3
